# 전력 관제 디자인

- 색상: canvas #F5F6F8, surface #FFFFFF, ink #191F28, secondary #6B7684, action #3182F6, warning #D97706.
- 서체: 시스템 한국어 산세리프(Apple SD Gothic Neo / Malgun Gothic), 숫자는 tabular-nums. 제목 30px, 수치 38px, 본문 15px.
- 레이아웃: 중앙 최대 1320px, 전체 왼쪽 정렬. 상단 얇은 브랜드 바, 두 탭, 기록 재생 제어, 넓은 전력 차트와 알림 사이드 패널. 모바일에서는 한 열.

```
브랜드                                         데이터 / 모델
전력 관제 | 비용 최적화
제목                                       날짜 / 기준 설정
현재 + 다음 예측 + 기준 여유
[시간 흐름 차트                           ][알림]
[재생 컨트롤                              ][생산 환경]
```

## 브리프 검토
토스의 밝은 바탕과 편안한 간격, 파란 액션을 따르되 금융 잔액 카드의 반복을 피한다. 이 공장의 실제 관측과 15분 후 단일 예측 사이 경계를 차트에서 보여주는 것을 핵심으로 삼는다. 모니터링은 실시간처럼 오인시키지 않고 기록 재생을 명시한다. 비용 화면은 수식 미정이므로 15분 가정 비교로 제한하며 계산 가정을 눈에 보이게 둔다.
