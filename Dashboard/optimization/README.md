# 시간당 공장인력 추천

## 시각 연결과 인원

관제와 날짜·시각을 공유한다. 11:45의 12:00 전력 예측과 raw 12시 생산량으로 12:00~13:00 인력을 추천한다. 12:00·12:15·12:30에는 동일 제안을 유지하고, 12:45에는 13:00~14:00 제안으로 갱신한다. 자정은 다음 날짜 raw 00시를 사용하며 정시 직전 예측/해당 정시 원자료가 없으면 미산정이다.

모델 자체는 다음 15분 예측이다. 전력비에는 정시 예측 전력(kW 가정)이 1시간 유지된다는 가정을 사용한다. 생산량은 원자료의 시간당 값 그대로이며 미리 알려진 목표로 간주한다.

해당 정시 날짜 이전의 같은 시간·평일/휴일 유형에서 목표 이상을 생산한 유효한 기록만 후보로 삼아 소수 인력을 올림한 최소 정수 인원을 선택한다. 대상 정시의 기존 인원은 제외한다. 교대·직무·휴게·설비 제약은 별도 확인해야 한다.

## 생산 이익과 비용

- 개당 생산 이익 초기값 150원: 인건비·전력비 차감 전 금액이다. 판매단가/매출로 표현하지 않는다.
- 예상 생산 이익 = 생산량 × 개당 생산 이익.
- 인건비 = 인원 × 적용 시급 × 1시간. 주간 8,720원, 야간 22~06시에는 입력 주간 시급의 1.5배.
- 전력량요금 = 정시 예측 전력 × 1시간 × 입력 요금표의 해당 계절·부하 단가.
- 기본요금 = 입력 기본 요금(초기 7,220원/kW) × 입력 작년 피크 전력(초기 200kW). 초기 월액은 1,444,000원이다. 1시간 배분은 월액÷달력일수÷24.
- 결과의 생산 이익−운영비는 추가 기타 비용·세금 등을 제외한 참고 금액이다.

후보 집합 안에서 `min(N×시급 + 전력량요금 + 기본요금 배분)`을 선택한다. 생산 이익과 전력비는 인원 N과 무관하므로 해당 입력 변경은 비용 결과를 바꾸며 추천 인원은 바꾸지 않는다.

## 입력 요금표

경부하/중간부하/최대부하 행과 여름/봄·가을/겨울 열의 9개 단가를 편집한다. 초기 값은 제공된 2021 고압A 선택I 표이다. 기본 요금도 표에서 편집한다. 계절·부하 시간대의 자동 선택은 config.json의 time_bands를 사용한다. 요청에 따라 부하 시간과 단위·출처·계산 안내 문구는 화면에서 삭제했다. 자동 계산 규칙은 유지한다.

상단 전력량 단가와 기본 요금은 적용된 표의 읽기 전용 값이다. 계산 조건이나 전력 요금표의 적용을 누르면 기본 요금·표 전체·생산 이익·시급을 적용한다. 각 항목의 기본값 저장 체크박스는 초기 선택 상태이다. 전력 요금표는 적용 시 기본 요금과 표 전체를 자동 저장하여 시간대가 바뀌면 해당 셀을 사용한다. 요금표의 저장 체크박스는 제거했다.

브라우저 localStorage 키 `kamp-optimization-defaults-v2`에 체크한 값과 표를 저장한다. 이전 판매단가/고정 전력단가의 v1 설정은 사용하지 않는다. 초기화 버튼은 v2 저장값을 지우고 150원/8,720원/기본 요금 7,220원/제공 요금표로 복원한다. 체크 해제 후 적용하면 해당 저장 기본값을 해제한다.

## 부하 시간대 근거 (2021년 재생 기준)

한전 공식 [기본공급약관 별표3, 42쪽](https://cyber.kepco.co.kr/ckepco/mobile/footer/pdf/201311/chapter9_131121.pdf#page=42)의 시간대와 제공된 `reference/elec_total_2021.pdf` 2쪽(2021.1.1 시행)을 대조했다. 공식 URL의 약관은 2013판이며, 아래 시간대가 제공된 2021 표와 동일함을 확인했다. 최신 연도 요금제로 치환하지 않는다.

| 부하 | 여름·봄가을 | 겨울 |
| --- | --- | --- |
| 경부하 | 23:00~09:00 | 23:00~09:00 |
| 중간부하 | 09:00~10:00, 12:00~13:00, 17:00~23:00 | 09:00~10:00, 12:00~17:00, 20:00~22:00 |
| 최대부하 | 10:00~12:00, 13:00~17:00 | 10:00~12:00, 17:00~20:00, 22:00~23:00 |

최적화 대상 정시부터 1시간에 맞는 부하·계절 단가를 적용한다. 예: 재생 12:45 → 대상 13:00~14:00 → 여름 최대부하. 일요일·2021년 공휴일은 전 시간 경부하이며, 공휴일이 아닌 토요일 최대부하는 중간부하로 계산한다.

## API와 실행

POST `/api/optimization`: `day`, `cursor`, `unit_price`(개당 생산 이익), `day_wage`, `rate_table`, `base_rate`(원/kW), `billing_peak`(작년 피크 전력 kW).
`rate_table`은 summer/spring_autumn/winter 각각에 off/mid/peak 숫자를 가진다. 기본 요금 및 피크 전력 범위 0~1,000,000, 전력량 요금 범위 0~100,000, 생산 이익 0~1,000,000, 주간 시급 0 초과~1,000,000. 유한한 값만 허용한다. 값 변경은 전역 설정이나 다른 브라우저의 값을 변경하지 않는다.

```sh
python3 -m optimization.verify
python3 -m optimization.export_plan --day 2021-07-12 --cursor 48
npm run build
npm start
```

`src/TariffTable.tsx`는 요금 입력표, `src/Optimization.tsx`는 입력 저장과 계산 화면, `optimization/engine.py`는 인력 및 비용 계산을 담당한다. 결과 내보내기는 `python3 -m optimization.export_plan`으로 실행하며 `output/hourly-*`를 생성한다. 생성 결과는 Git에서 제외한다. 상세 근거와 재생 컨트롤은 자원 탭에서 제거했으며 시점 이동은 관제 탭을 사용한다.

작년 피크 전력은 계산 조건의 기본 요금 아래에서 편집한다. ‘기본값’을 체크하고 적용하면 브라우저에 저장한다. 체크 해제 후 적용하면 저장값을 해제하며 다음 로딩 시 200kW로 복원한다. 초기화 시에도 200kW로 복원한다. 시간당 영업 이익은 생산 이익 합계에서 해당 1시간 운영비를 뺀 원화 금액이다.
