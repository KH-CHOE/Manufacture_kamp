# 순환신경망(GRU) 다음 15분 전력 예측

딥러닝 파트 담당분 정리입니다. `Modeling/`(정병근, ExtraTrees)과 **같은 행·같은 분할**에서
평가해 수치를 바로 비교할 수 있게 맞췄습니다.

가이드북 본문 알고리즘이 Random Forest + 순환신경망이라, 순환 계열을 끝까지 다듬어 보고
**어디까지 되는지와 어디서 무너지는지**를 함께 기록했습니다.

## 핵심 파일

- `rnn_input_data.csv`: 15분 전력 계열과 달력 변수, 분할 표시를 담은 24,190행 CSV.
  `split`은 train/test/boundary_excluded — **`Modeling/final_input_data.csv`와 같은 분할**입니다.
- `selection.json`: 전진검증으로 확정한 최종 구성과 선정 규칙, 탐색 요약, 기각한 가설.
- `train_rnn.py`: 최종 구성 재학습과 시험 지표 재현. **시드 3개**를 돌려 평균과 범위를 냅니다.
- `predict_rnn.py`: 저장 모델로 예측. 15분 전력 계열을 받아 창을 만들어 씁니다.
- `prepare_rnn_input.py`: 원본 CSV에서 입력 재생성. `--align`으로 정병근 분할에 맞춥니다.
- `evidence/`: 창 길이·자료량·학습예산·검증창·시드·은닉크기 탐색과 진단 기록 9건.
- `requirements.txt`: 검증에 사용한 패키지 버전.

## 실행

```bash
python train_rnn.py                 # 시드 3개, 직전 3개월 학습 (최종 구성)
python train_rnn.py --months 0      # 전체 구간 학습으로 비교
python predict_rnn.py
```

원본부터 입력을 다시 만들려면:

```bash
python prepare_rnn_input.py --raw <okm_augumented_2021.csv> --align ../Modeling/final_input_data.csv
```

`--align`을 주면 정병근 입력과 **시각·정답이 일치하는지 검증**하고 그의 `split`을 그대로
따릅니다. 생략하면 같은 분할을 날짜 규칙(20210627~ 시험)으로 재현합니다.

## 트리 모형과 무엇이 다른가

트리 모형은 시차 변수를 **미리 펼쳐서** 줍니다(`과거전력_1칸`, `과거전력_96칸` …).
순환신경망은 **과거 96칸을 순서대로 먹으면서** 기억을 갱신합니다. 그래서 입력 CSV에
시차 변수를 만들어 두지 않고 전력 계열 한 열과 달력 변수만 담았습니다. 창은 학습 시점에
만듭니다.

창 96칸을 **24스텝 × 4채널**로 접어 넣습니다(`daily` 재구성). 96스텝을 그대로 흘리는 것보다
계산이 가볍고, 15분 과제에서는 성능도 같았습니다. 다만 **긴 창에서는 쓰면 안 됩니다** —
시간 해상도 실험에서 창 168을 24스텝 × 7채널로 접으니 한 스텝에 "7일 전 이 시각, 6일 전
이 시각 …"이 한꺼번에 들어가 시간 순서가 사라지고 3.2배 나빠졌습니다(`evidence/07`).

삭제된 2021-07-13·07-15를 **건너뛰는 창은 제외**합니다. 시각이 연속하지 않는 창을 학습에
넣으면 존재하지 않는 시간 흐름을 배웁니다. 24,190행에서 유효 창 23,904개가 나옵니다.

## 수치와 해석

**시험 구간 20210627~0914 · 유효 창 7,104개** (시드 42·2024·7)

| 시드 | 시험 MSE | MAE | R² | 에폭 |
|---|---|---|---|---|
| 42 | 61.440 | 5.244 | 0.9838 | 70 |
| 2024 | 61.460 | 5.204 | 0.9838 | 92 |
| 7 | 60.167 | 5.160 | 0.9842 | 71 |
| **평균** | **61.022** | 5.202 | 0.9839 | — |
| 범위 | [60.167, 61.460] | | | |
| **세 시드 예측 평균** | **56.928** | **4.983** | | |

**세 시드의 예측을 평균내면 56.928**로, 개별 최고(60.167)보다 낫습니다. 시험 성적을 보고
고른 것이 아니라 **미리 정한 절차**(시드 3개를 돌려 평균)의 결과이므로 그대로 보고합니다.

### `Modeling/`(ExtraTrees)과의 비교 — 행을 맞춰야 합니다

시험 7,294행 중 **190행은 순환신경망이 만들 수 없습니다.** 삭제된 2021-07-13·15를
건너뛰는 창이라 제외됩니다. 그런데 **그 190행이 쉬운 구간**입니다 — 거기서 ExtraTrees의
MSE가 16.05로, 전체 평균보다 훨씬 낮습니다. 그래서 같은 행으로 맞추면 수치가 달라집니다.

| 모델 | 7,294행 | **공통 7,104행** |
|---|---|---|
| ExtraTrees (`Modeling/`) | 60.163 | **61.343** |
| GRU 시드 평균 (이 폴더) | — | **56.928** |

**같은 행에서는 순환신경망이 7.2% 낮습니다.** 다만 아래 두 가지를 함께 봐야 합니다.

1. **이 시험 구간은 선정에 쓰지 않았지만, 양쪽 모두 이미 여러 번 관찰한 구간**입니다.
   정병근 보고서의 같은 단서가 여기에도 적용됩니다
2. **선정 기준인 전진검증에서는 순환 계열이 밉니다.** 우리 실험(24,000행 기준)에서
   전진검증 4구간 평균이 순환신경망 75.59 · 부스팅 63.65 입니다.
   아래 "어디서 무너지는가"가 그 이유입니다

> **행 기준이 다른 수치를 섞지 마세요.** 7,104행(이 폴더) · 7,294행(`Modeling/`) ·
> 24,000행(우리 전진검증 실험)이 각각 다릅니다. 비교할 때는 같은 기준끼리만 놓습니다.

## 무엇을 탐색했나

전부 **전진검증 4구간(04/01·05/01·06/01·07/01 각 24일) 평균 MSE**로 판정했습니다.
평가 구간은 선정에 쓰지 않았습니다.

| 축 | 비교한 것 | 결과 |
|---|---|---|
| 창 길이 | 96 / 144 / 192 / 240 / 288 | 96이 최선. 자료량을 3개월로 고정해도 유지 |
| 구조 | GRU / LSTM | 15분 과제에서는 GRU가 일관되게 낫다 |
| 재구성 | flat / daily | 짧은 창은 동일, 긴 창에서 daily가 3.2배 나쁘다 |
| 학습 구간 | 전체 / 직전 3개월 / 최근가중 | 직전 3개월 |
| 은닉 크기 | 64 / 128 / 256 | 256 (전진검증 91.64 → 86.08) |
| 학습 예산 | 에폭 상한 200 / 600 | 600은 과적합으로 악화 |

## 기각한 가설 — 왜 순환 계열이 전진검증에서 밀렸나

순환 계열이 트리 모형에 밀리는 이유를 찾느라 가설을 차례로 세우고 검증했습니다.
**넷을 기각하고 하나를 부분 확인**했습니다.

| 가설 | 판정 | 결정적 근거 |
|---|---|---|
| 오래된 자료가 오염원 | 기각 | 같은 처방(최근 3개월 학습)을 부스팅에 주니 63.65 → 68.07로 **나빠진다** |
| 학습 예산 부족 | 기각 | 예산 3배에 두 조건 다 악화, 격차는 13.22 → 17.15로 **벌어짐** |
| 자료량이 많아야 유리 | 기각 | 자료를 줄인 쪽이 계속 이긴다 |
| 조기 종료 검증 창의 위치 | 대체로 기각 | 격차 11.48 중 **1.27(11%)** 만 설명 |
| 모형 용량 | 부분 성립 | 은닉 4배로 격차의 **48.5%** 를 메웠다 |

예산 가설을 기각한 근거가 깨끗합니다. 04/01 구간은 3개월 제한이 자료 시작과 겹쳐
**두 조건의 학습 자료가 소수점까지 같습니다.** 그런데 예산만 바꾸니 122.92 → 168.09(+37%)
— 내부 검증 손실은 계속 줄었는데 다음 구간 성능은 나빠졌습니다. 순수한 과적합입니다.

## 시드를 3개 돌리는 이유

탐색 도중 한 설정이 **시드 42에서 평가 54.99, 시드 7에서 135.30**으로 2.5배 벌어진 적이
있습니다. 더 문제는 **시드 7의 전진검증이 세 시드 중 가장 좋았다**는 것입니다
(80.026 대 80.275 / 80.183). 즉 전진검증이 그 취약점을 경고하지 못했습니다.

원인은 구간 구성입니다 — 전진검증 4구간에는 **장기 휴무가 없고** 평가 구간에는 하계휴무
(7/31~8/8)가 있습니다. **평가 구간에만 있는 사건의 취약성은 전진검증이 구조적으로 못
잡습니다.** 그래서 시드 3개의 평균과 범위를 함께 보고합니다.

(그 파국은 나중에 **용량 부족** 때문으로 밝혀졌습니다. 은닉을 64 → 256으로 키우니 같은
시드가 51.805로 안정됐습니다. `evidence/05`·`evidence/06`)

## 어디서 무너지는가 — 조건별 성능

평가 구간을 쪼개 보면 순환 계열과 트리 계열이 **서로 반대 조건에서 강합니다**.

| 구간 | 행수 | 부스팅 | 순환신경망 | 승자 |
|---|---|---|---|---|
| 하계휴무 7/31~8/8 | 864 | **3.94** | 7.18 | 부스팅 82% 앞 |
| 평시 | 4,127 | 76.60 | **58.95** | 순환신경망 23% 앞 |

그리고 **맞혀야 하는 기간이 격주로 뒤집히면 순환 계열이 크게 무너집니다.**
이 공장은 5월에 월요일 새벽 조업이 멈췄는데, 4월은 그 전환이 진행 중이라 월요일 새벽이
21.9 / 85.4 / 20.9 / 90.2로 교대합니다(주간편차 38.4, 다른 달은 0.4~6.3).

| 구간 | 맞힐 기간 | 주간편차 | 부스팅 | 순환신경망 | 순환 우세 |
|---|---|---|---|---|---|
| 04/01 | 04/01~04/24 | **36.9** | 73.92 | 120.46 | **−63.0%** |
| 05/01 | 05/01~05/24 | 1.2 | 44.60 | 45.62 | −2.3% |
| 06/01 | 06/01~06/24 | 0.2 | 21.43 | 22.61 | −5.5% |
| 07/01 | 07/01~07/24 | 0.2 | 114.64 | 119.97 | −4.7% |
| 평가 | 07/25~09/14 | 1.3 | 64.02 | **50.70** | **+20.8%** |

**순환 계열의 전진검증 열세는 거의 전부 한 구간에서 나옵니다.** 안정 구간 셋은 사실상
동률(−4.2%)이고, 조업이 안정되면 오히려 앞섭니다.

이유는 구조입니다. 순환신경망은 **함수 하나**를 학습하므로 "이번 주는 돌고 다음 주는
쉰다"는 격주 교대를 표현할 방법이 없습니다. 트리 모형은 달력 변수로 **분기**해 두 경우를
따로 담습니다.

## 그래서 어디에 쓰면 되는가

**주 모델로는 트리 계열을 권합니다.** 실전에서 다음 구간이 안정될지 전환기일지 미리 알 수
없는데, 안정 구간에서 20% 더 좋은 대신 전환기에 63% 무너지는 모형은 고르기 어렵습니다.

대신 **두 모형을 함께 돌리고 예측이 크게 갈리는 구간을 경고 신호로 쓰는 것**을 제안합니다.
일치하면 안정 구간일 가능성이 높고, 갈리면 조업 패턴이 바뀌는 중일 수 있습니다.
사후 진단으로 찾은 체제 전환을 실시간으로 잡는 방법입니다.
