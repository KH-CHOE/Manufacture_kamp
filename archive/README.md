## 왜 남겨 두나

지우면 **어떤 주장을 왜 철회했는지** 따라갈 수 없다. 이 세 폴더에는 틀렸다가 바로잡은
기록이 들어 있다 — 창 168이 해롭다는 주장, 오래된 자료가 오염원이라는 주장,
순환신경망이 평가에서 앞선다는 주장을 모두 근거와 함께 철회했다.
각 폴더의 `README.md` 와 `evidence/` 에 그 경위가 있다.

## 지금 쓰는 것은 여기가 아니다

현행 전처리·모델링은 **`functions/modeling/`** 이다. 같은 결론을 원자료부터 다시 짠 판이고,
전처리가 하나라 모든 모델이 같은 행에서 비교된다.

**행 기준이 다르다 — 섞어 읽지 말 것.** 아카이브의 수치는 폴더마다 기준이 다르다
(시험 행수 4,991 / 7,104 / 7,294 / 23,425 / 23,904). `functions/modeling/results.json`
의 수치는 24,576행 공통 기준이다.
