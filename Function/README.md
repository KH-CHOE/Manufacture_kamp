# 전처리·학습·예측 코드

원본은 `Dataset/raw/`, 전처리 결과는 `Dataset/preprocessed/`, 저장 모델과 평가 결과는 `Model/`에 둔다. 실행 환경 설치는 [루트 README](../README.md)를 따른다.

## 실행

저장소 루트에서 가상환경을 활성화한 뒤 실행한다.

```bash
python Function/preprocessing.py
python Function/modeling.py
python Function/verify_pipeline.py
python Function/verify_regressions.py
python Function/verify_training.py
python Function/verify_serving.py
```

전체 학습은 기준선·RandomForest·ExtraTrees·HistGradientBoosting·GRU·LSTM·고정 반반 결합을 비교한다. 신경망은 검증 4구간과 시험 1구간에서 각각 시드 3개를 학습하므로 시간이 걸린다.

완료한 신경망 학습은 `Function/_net_cache/`에 시드별로 저장한다. 같은 데이터·코드·설정으로 다시 실행하면 완료한 부분을 재사용한다. 이 폴더는 Git에 올리지 않는다. CPU 작업은 최대 4개를 함께 실행하며, 각 학습은 CPU 스레드 하나를 사용한다.

빠른 트리 실험은 다음과 같다.

```bash
python Function/modeling.py --models baseline,rf,et,hgb
```

부분 학습도 `results.json`과 모델 검증 기록을 바꾼다. 대시보드용 모델 묶음을 갱신할 때는 전체 학습 명령을 사용한다. 서로 다른 실행의 트리·GRU를 섞으면 실행 검사가 실패한다.

## 다른 연도 자료

```bash
python Function/preprocessing.py --raw 새자료.csv --out 정리자료.csv
python Function/preprocessing.py --raw 새자료.csv --out 정리자료.csv --calendar Function/calendar_2022.json
python Function/preprocessing.py --raw 새자료.csv --out 정리자료.csv --no-calendar
```

달력 인수를 생략하면 원자료의 연도에 맞는 `Function/calendar_YYYY.json`을 찾는다. 없으면 주말만 휴일로 보고 날짜 순서 뒤 30%를 시험 자료로 나눈다. `--no-calendar`는 달력을 명시적으로 사용하지 않는다. 원자료와 달력 연도가 다르거나 학습·시험 중 한쪽이 비면 오류로 중단한다.

`--split-date YYYYMMDD`로 분할 날짜를 직접 정할 수도 있다. 달력에 기록된 분할 날짜보다 직접 지정한 날짜가 우선한다.

## 전처리 규칙

- 시간은 0~23 정수이며 날짜 안에서 중복되지 않아야 한다. 잘못된 값은 완전한 정상일의 행 순서를 근거로 복구하고, 근거가 부족하면 해당 날짜를 제외한다. 시간이 정상인 불완전한 날짜는 유지한다.
- 평균 전력·공장인원처럼 전력을 역산할 수 있는 열과 달력을 다시 적은 열은 모델 입력에서 제외한다.
- 결측값은 과거 자료의 통계로 대치한다. 시간 공백을 넘어 시차나 이동평균을 만들지 않는다.
- 한 시간의 네 전력값을 15분 간격으로 펼친다. `kW`가 현재 관측, `y`가 다음 15분의 정답이다.
- 생산량처럼 시간이 끝나야 확정되는 누적값은 지연한 열을 따로 만든다.
- `processed_manifest.json`에 처리 이유·행수·분할·환경과 입력/출력 파일 지문을 기록한다.

## 모델 비교 기준과 한계

모든 모델은 결측이 없고 과거 96개 관측이 연속인 **동일한 평가행**을 사용한다. 신경망 입력 창은 필터링 전의 원래 시간축에서 만들고, 공통행의 끝점만 선택한다. 학습과 저장 모델 추론이 같은 함수를 사용한다.

| 모델 | 입력·학습 방식 |
|---|---|
| 직전값 유지 | 현재 전력값을 다음 값으로 사용 |
| 시각×요일 중앙값 | 학습 자료에서 같은 시각·요일의 중앙값 계산 |
| RandomForest | 시차·이동통계·달력 입력. `bootstrap=True`로 표본 재추출 |
| ExtraTrees | 같은 트리 입력. `bootstrap=False`, 무작위 분할 |
| HistGradientBoosting | 같은 트리 입력, 별도 학습 설정 |
| GRU·LSTM | 과거 96개 전력값과 달력 변수. 직전 3개월, 시드 3개 예측 평균 |
| 결합 | ExtraTrees와 GRU 예측을 고정 0.5씩 결합 |

트리는 평가 시작 전 전체 기간을 학습하고 신경망은 직전 3개월을 사용한다. 신경망은 그중 앞 85%로 학습하고 뒤 15%로 조기 종료를 결정한다. **평균·표준편차도 앞 85%에서만 계산한다.** 입력 정보와 학습 예산이 다르므로 점수 차이를 알고리즘 자체의 우열로 단정하지 않는다.

선정 기준은 전진검증 평균 MSE(오차 제곱의 평균, 낮을수록 좋음)다. 시험 점수로 시드·가중치·설정을 고르지 않는다. 네 검증 구간만으로 작은 차이가 확실하다고 단정하지 않는다.

`Model/results.json`은 전체 비교이고, `Model/duplicate_evaluation.json`은 학습에 있던 하루 전력 곡선이 검증에 반복된 영향을 확인하는 보조 평가다. 보조 평가는 반복 날짜를 평가에서만 제외한다. 불완전한 하루와 근사 중복은 잡지 못하며, 제외 후 날짜 수가 적은 구간은 특히 불확실하다.

이번 수정은 이미 한 번 평가한 시험 자료에서 오류를 고친 재평가다. 완전히 새로운 외부 자료에서 검증한 성능으로 볼 수 없다.

## 저장 파일과 화면

- `.joblib`: 학습된 트리와 입력 열. scikit-learn **1.2.2**에서 저장·실행한다.
- `.pt`: 신경망의 시드별 가중치, 표준화 통계, 입력 설정. 추론 자료로 통계를 다시 계산하지 않는다.
- `Model/manifest.json`: 모델·결과·자료의 파일 지문, 평가행과 라이브러리 버전. 내용이 다른 모델을 섞거나 scikit-learn 버전이 다르면 중단한다.
- `net_infer.py`: 신경망 추론을 별도 프로세스로 실행한다. sklearn과 PyTorch의 OpenMP 충돌을 피한다.
- `verify_serving.py`: 저장물만으로 시험 점수와 평가행을 재현하는지 검사한다.

RandomForest 저장물은 Git에서 제외되어 있다. 직접 사용하려면 재학습한다.

## 인원·비용 계산의 의미

계획 생산량을 사용자가 직접 입력한다. 미래의 실제 생산량을 자동으로 가져오지 않는다. 과거의 같은 시간·날 유형 자료에서 계획 생산량 이상인 사례를 찾는다.

원자료의 `공장인원`은 `생산량 ÷ 네 전력값의 합`으로 만든 파생값이다. 실제 배치 인원이 아니므로 **올림한 값을 참고 비용 가정에만 사용**하며, 필요한 최소 인원이라고 해석하지 않는다. 사례가 없으면 인원과 관련 비용을 산정하지 않는다.

전력 비용은 다음 15분 예측 전력이 한 시간 유지된다는 가정이다. 전기요금표도 2021년 기준이므로 실제 청구액이나 현재 요금표를 뜻하지 않는다.
