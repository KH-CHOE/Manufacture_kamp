# Foundry Guard · Live 데모 발표 대본

> 4분 30초 라이브 시연 대본. 각 막마다 **화면 상태 → 발표자 행동(버튼/음성) → 멘트 → 확인 포인트**.
> 핵심 메시지: "통계·ML은 기본기, 우리 차별점은 **현장이 실제로 쓰는 관제·대응 시스템**."

## 0. 사전 준비 (발표 전)

```bash
cd ~/code/active-projects/project_KAMP
.venv/bin/uvicorn app:app --port 8100
```
- 브라우저에서 **http://127.0.0.1:8100/live** → **전체화면(F11)**
- **스피커 켜기**(음성 답변·경보), 마이크 권한 허용
- 시작 상태: **↺ 리셋** 눌러 깨끗하게. 속도 **1x**.
- (선택) `.env`에 OpenAI 키 있으면 🎤 상태가 "OpenAI Realtime", 없으면 "브라우저 인식(무키)" — **둘 다 데모 가능**
- 네트워크 백업: 음성인식은 인터넷 필요 → 불안하면 휴대폰 핫스팟. 최후엔 **텍스트 입력창**으로 동일 시연 가능

---

## 1. 오프닝 (0:00–0:30) — 프레이밍

- **화면**: 라인 미믹 정지 상태, 상단 "● 시뮬레이션 데모" 배지 + 정직 표기 띠
- **멘트**: "불량 예측 모델은 이제 누구나 만듭니다. 문제는 그 모델이 **현장에서 실제로 작동하느냐**입니다. 저희는 그걸 관제 시스템으로 구현했습니다."
- **행동**: 정직 표기 띠 가리키며 — "제어 대상은 가상 라인이고, 재생하는 건 **2021년 실제 조업 데이터**입니다. 지어낸 값이 아닙니다."

## 2. Act 1 · 평상시 관제 (0:30–1:15)

- **행동**: **▶ 재생** 클릭 (속도 1x, 필요시 2x)
- **화면**: 데이터가 흐르고 지점이 녹색, 우측 **주기 현황 보고** 자동 갱신
- **멘트**: "정상 운전 상태입니다. 시스템이 주기적으로 스스로 현황을 요약합니다."
- **확인**: 파이프 흐름 애니메이션, 현황보고 문장 갱신

## 3. Act 2 · 이상 포착 (1:15–2:15) ★정직함이 무기

- **행동**: **⟶ 실제 불량 시점으로** 클릭 (실데이터의 진짜 불량 직전으로 이동)
- **멘트**: "이제 실제로 불량이 났던 시점으로 갑니다."
- **화면**: 확률 게이지 상승 → 임계 돌파 → **금형 지점 적색** + **이상 이력**에 경보 + (음성 켜져있으면) TTS 경보
- **멘트**: "시스템이 이상을 스스로 감지하고, 원인까지 제시합니다."
- **확인**: 하단 원인 패널에 이탈 변수(A등급), "통계적 관계이며 인과는 아님" 문구
- **팁**: 무대에서 실불량이 안 잡히면 **⚠ 이상 강제주입**으로 대체(최후 안전망)

## 4. Act 3 · 음성으로 대응 (2:15–3:30) ★핵심

발표자가 말로만 조작 (🎤 음성 켠 상태):

1. 🎤 **"왜 위험해?"** → 음성으로 원인 답변
2. 🎤 **"임계값 0.6으로 낮춰"** → **조정 창**이 열리고 AI가 값·시뮬레이션 결과 제안
   - **멘트**: "음성은 틀릴 수 있으니, AI는 값을 **제안만** 하고 최종 적용은 사람이 확인 후 버튼으로 합니다." → **[적용]** 클릭
3. 🎤 **"라인 정지"** → 정지 확인 창 → **[정지 승인]** → 라인 정지, **감사 로그** 기록
- **확인**: 조정창의 "사람이 승인해야 반영" 문구, 감사 로그 행 추가

## 5. Act 4 · 안전한 재개 (3:30–4:15) ★안전 포인트

- **행동**: 위험 상태에서 🎤 **"라인 재시작"**
- **화면**: **인터록** 발동 — "이탈 변수 미해소, 오버라이드 필요"
- **멘트**: "위험이 해소되지 않으면 함부로 못 켭니다. 강제 재시작은 별도 확인을 거칩니다." → 오버라이드 체크 → **[재시작 승인]**
- **행동**: 감사 로그 패널 가리키기 — "모든 명령이 시간·주체·결과로 기록됩니다."
- **확인**: 감사 로그에 정지/차단(인터록)/재시작 이력

## 6. 클로징 (4:15–4:30)

- **멘트**: "모델 성능(PR-AUC 0.853)은 기본기입니다. 저희 차별점은 이 모델을 **현장이 실제로 쓸 수 있는 관제·대응 시스템**으로 만든 것입니다."
- 정직 표기 띠 다시 가리키며 — "오늘 제어 대상은 시뮬레이터입니다. 실제 설비에서는 이 명령들이 **운영자 승인이 필요한 제안**으로 전달됩니다."

## 음성/텍스트 명령·질문 모음 (리허설용)

| 종류 | 말 | 결과 |
|---|---|---|
| 질문 | "지금 상태 어때?" | 현재 위험도·고위험 건수 음성 답변 |
| 질문 | "왜 위험해?" | 이탈 변수 원인 음성 답변 |
| 질문 | "고위험 몇 건이야?" | 누적 고위험 건수 |
| 질문 | "임계값 얼마야?" | 현재 임계값·오탐·미탐·비용최적 |
| 명령 | "임계값 0.6으로 낮춰" | 임계값 조정 창(제안→승인) |
| 명령 | "라인 정지" | 정지 확인 창 |
| 명령 | "재시작" / "가동" | 재시작(위험 시 인터록) |

## 트러블슈팅

- **음성 안 잡힘**: 하단 **텍스트 입력창**에 같은 문장 입력 → **명령→**. 시연 동일.
- **너무 빠름/느림**: 속도 0.25x~8x 조절.
- **꼬였을 때**: **↺ 리셋** 후 Act 2부터 다시.
- **경보가 안 뜸**: **⚠ 이상 강제주입**으로 확실히 이상 상태 유발.
